# 💎 Interactive Pricing Cards

**Interactive Pricing Cards** is a responsive and dynamic pricing section built using HTML, CSS, and JavaScript. The project features interactive pricing cards with monthly/yearly price switching, category filtering, and smooth hover effects to create an engaging user experience.

<img width="1416" height="877" alt="image" src="https://github.com/user-attachments/assets/f1bff7c1-f7bf-4cdd-8424-7edf1e0250e5" />


## 🌟 Features

- **Pricing Cards:** Displays 3–4 pricing or product cards with icons/images, titles, descriptions, prices, feature lists, and buttons.
- **Monthly/Yearly Toggle:** Switches between monthly and yearly pricing dynamically.
- **Category Filters:** Allows users to filter cards using three options:
  - All
  - Basic
  - Premium
- **Interactive Cards:** Includes smooth hover effects such as lifting, shadows, or glowing effects.
- **Most Popular Badge:** Highlights one pricing card with a "Most Popular" badge.
- **Active Filter Styling:** Visually highlights the currently selected filter button.
- **Responsive Design:** Uses CSS Flexbox or Grid to ensure the cards adjust to different screen sizes.
- **Dynamic Content:** Updates card prices and visibility using JavaScript.

## 🛠️ Technologies Used
